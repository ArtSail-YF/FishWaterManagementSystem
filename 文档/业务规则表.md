## 业务规则表

| 规则ID | 模块       | 条件                                                            | 动作                                                                                                                     |
| ------ | ---------- | --------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| R001   | 基础数据   | 删除基地时，该基地下存在塘口                                    | 禁止删除，提示关联影响                                                                                                   |
| R002   | 基础数据   | 删除塘口时，该塘口存在关联生产日志                              | 禁止删除                                                                                                                 |
| R003   | 基础数据   | 删除物资时，该物资被生产日志或用药记录引用                      | 禁止删除                                                                                                                 |
| R004   | 基础数据   | 删除供应商时，该供应商有关联物资                                | 禁止删除                                                                                                                 |
| R005   | 数据采集   | 物联网传感器数据上报                                            | 自动存储，标记 `data_source='iot'`，前端显示🤖图标                                                                     |
| R006   | 数据采集   | 人工录入水质数据（如pH）                                        | 标记 `data_source='manual'`，前端显示✍️图标                                                                          |
| R007   | 生产计划   | 重要计划（用药、收获）创建                                      | 需技术总监或品控管理员审批，通过后自动生成任务                                                                           |
| R008   | 生产计划   | 计划到达开始时间                                                | 状态自动从“已发布”转为“执行中”                                                                                       |
| R009   | 生产计划   | 执行中的计划需要修改                                            | 不可编辑内容，但可申请延期或取消，可添加“调整说明”备注                                                                 |
| R010   | 生产计划   | 未开始的计划被编辑                                              | 修改记录留痕，无需审批                                                                                                   |
| R011   | 生产计划   | 执行中的计划申请延期                                            | 负责人申请 → 管理员批准 → 状态变为“已延期” → 到达新时间自动恢复“执行中”                                           |
| R012   | 生产计划   | 计划被管理员取消                                                | 状态变为“已取消”，不再提醒                                                                                             |
| R013   | 生产计划   | 创建用药计划且与现有收获计划冲突（休药期截止日 > 计划上市日）   | 弹窗预警，但不阻止创建                                                                                                   |
| R014   | 生产计划   | 创建收获计划时存在未过休药期的用药记录                          | 预警，计划可继续创建但标记“高风险”                                                                                     |
| R015   | 日志录入   | 工人点击计划提醒卡片的“录日志”                                | 自动打开日志表单，预填塘口、操作类型、计划值、当前时间                                                                   |
| R016   | 日志录入   | 工人保存日志时，存在 `plan_id`                                | 自动计算偏差 `\|实际-计划\|/计划`，日志与计划锚定                                                                        |
| R017   | 日志录入   | 日志实际值与计划值偏差 ≥ 20%（可配置）                         | 标记 `need_review=true`，推送管理员审核，记录偏差预警                                                                  |
| R018   | 日志录入   | 工人手动录入日志（无计划关联）                                  | 正常保存，不与任何计划关联，PC端无偏差对比                                                                               |
| R019   | 日志录入   | 工人修改计划值且偏差 < 20%                                      | 无预警，正常保存                                                                                                         |
| R020   | 日志录入   | 工人修改计划值且偏差 ≥ 20%                                     | 强制拍照，自动标记异常，推送管理员                                                                                       |
| R021   | 日志录入   | 工人更正已保存的日志                                            | 需拍照+说明原因，与原值对比产生偏差预警，管理员审核                                                                      |
| R022   | 日志录入   | 工人拍照上传                                                    | 调用手机摄像头（禁止从相册），照片自动叠加水印（时间、GPS、塘口、操作类型、工人ID）                                      |
| R023   | 离线录入   | App启动时无网络                                                 | 进入离线工作模式，数据存入本地SQLite，显示“待同步X条记录”                                                              |
| R024   | 离线录入   | 本地缓存超过500条                                               | 提示清理                                                                                                                 |
| R025   | 离线录入   | 网络恢复                                                        | 自动批量同步本地数据至云端，指数退避重试最多5次                                                                          |
| R026   | 离线录入   | 云端已存在相同时间、塘口的记录（冲突）                          | 保留两条记录，标记“冲突待审核”，管理员PC端人工合并                                                                     |
| R027   | 文员代录   | 文员代录日志                                                    | 自动记录 `created_by`(文员ID)、`source='admin'`、`actual_worker_id`，强制选择代录原因，强制上传佐证材料（至少1张） |
| R028   | 文员代录   | 文员代录后                                                      | 推送App通知给对应工人，要求24小时内确认或申诉；超24小时未确认则自动生效                                                  |
| R029   | 补录       | 补录时间在操作发生后48小时内                                    | 允许普通补录，需上传凭证，填写原因                                                                                       |
| R030   | 补录       | 补录时间超过操作后48小时                                        | 需管理员PC端审批，并上传充分佐证材料                                                                                     |
| R031   | 补录       | 紧急模式开启时补录                                              | 补录窗口延长至72小时，不强制拍照，偏差预警不推送                                                                         |
| R032   | 补录       | 紧急模式关闭后                                                  | 列出未拍照的日志，提醒72小时内补传照片；超72小时未补传则标记“凭证缺失”                                                 |
| R033   | 补录       | 补录日志保存                                                    | 标记 `is_backfilled=true`，记录补录时间、补录人、补录原因，PC端橙色背景高亮                                            |
| R034   | 补录       | 工人/塘口的补录比例超过30%（可配置）                            | 自动推送预警给管理员                                                                                                     |
| R035   | 预警       | 溶氧 < 2mg/L（可配置）                                          | 触发预警，网格视图标红，水质列表置顶，推送移动端                                                                         |
| R036   | 预警       | 设备离线 ≥ 30分钟                                              | 触发预警                                                                                                                 |
| R037   | 预警       | 超12小时（可配置）未投喂                                        | 触发预警                                                                                                                 |
| R038   | 预警       | 气象蓝色/黄色预警                                               | PC端预警中心记录/高亮，App内通知/弹窗+短信                                                                               |
| R039   | 预警       | 气象橙色预警                                                    | PC端强制弹窗，App强弹窗+短信+语音播报，建议用户确认                                                                      |
| R040   | 预警       | 气象红色预警                                                    | PC端红闪+强制弹窗，App语音播报+震动+短信+电话，强制要求点击“已确认”                                                    |
| R041   | 预警       | 红色预警发出后30分钟（可配置）无人确认                          | 自动升级通知（重复电话、短信至所有管理员），PC端高亮未确认列表                                                           |
| R042   | 预警       | 台风预警与天文大潮叠加                                          | 自动计算风暴潮风险等级（低/中/高/极高），预警详情标注“注意海水倒灌”，推送特殊避险建议                                  |
| R043   | 预警       | 人工录入的pH值超出正常范围（如<5或>9）                          | 触发预警记录（可配置是否强制推送），水质列表中高亮提示                                                                   |
| R044   | 预警       | 红色/橙色预警被确认                                             | 进入处置步骤                                                                                                             |
| R045   | 预警       | 现场人员在App填写处置结果并上传照片                             | 预警状态由“待处理”变为“已处理”                                                                                       |
| R046   | 休药期     | 工人录入用药                                                    | 系统自动识别药品休药期天数，计算休药期截止日 = 用药时间 + 休药期天数，保留所有历史记录                                   |
| R047   | 休药期     | 塘口尚无计划上市日期时录入用药                                  | 仅记录用药，标记“存在用药记录”，不触发警告                                                                             |
| R048   | 休药期     | 塘口已有计划上市日期，且计划上市日 < 任一用药记录的休药期截止日 | 触发强提醒弹窗，列出冲突药品及剩余天数，询问是否继续录入                                                                 |
| R049   | 休药期     | 强提醒后工人选择“取消录入”                                    | 放弃本次用药记录，原有风险标记不变                                                                                       |
| R050   | 休药期     | 强提醒后工人选择“坚持录入”                                    | 保存用药记录，标记塘口“休药期风险”（红色角标），记录违规原因；若已有风险则升级为高风险，额外推送预警                   |
| R051   | 休药期     | 同一塘口再次录入用药，且已有未过休药期的记录                    | 重新计算所有休药期截止日，再次强提醒，文案明确指出“休药期将进一步延长”                                                 |

| R066   | 监控       | 人工录入pH超出正常范围                                          | 触发预警记录（可配置不强制推送），水质列表高亮提示                                                                       |
